# Decision report template

Pass the object below as the `report` argument of `record_decision_report`. It is validated against
`trader.domain.DecisionReport` (a test keeps this template valid).

**Only these keys are allowed.** Unknown keys (for example `summary`, `mode`, top-level `evidence_ids`) are rejected.

```json
{
  "as_of": "2026-11-10T15:52:26Z",
  "symbol": "BTCUSDT",
  "horizon": "24h",
  "decision": "WATCH",
  "market_regime": {
    "label": "range/vol_high",
    "model_or_method": "rule_regime_v1",
    "evidence_ids": ["ev_00000000000000000001"]
  },
  "quantitative_evidence": [
    {
      "kind": "observed_fact",
      "statement": "1h regime is range/vol_high; 4h is trend_down/vol_high; 1d is trend_up/vol_normal.",
      "evidence_ids": ["ev_00000000000000000001"]
    },
    {
      "kind": "model_estimate",
      "statement": "Both baseline strategies are flat and not validated.",
      "evidence_ids": ["ev_00000000000000000002"]
    }
  ],
  "ml_evidence": [],
  "news_evidence": [],
  "knowledge_references": [],
  "supporting_arguments": ["Price is near the lower edge of the 4-day range."],
  "counter_evidence": ["The 4h trend is down and the timeframes disagree."],
  "uncertainties": ["One missing 1h bar; data quality is degraded."],
  "invalidation_conditions": ["A 1h close above the Donchian entry level would change the view."],
  "entry_plan": null,
  "stop_plan": null,
  "exit_plan": null,
  "expected_net_return": null,
  "risk_assessment": null,
  "source_freshness": {"market_snapshot": "2026-11-10T15:52:26Z"},
  "model_versions": [],
  "data_quality_status": "degraded",
  "llm_confidence_label": "low",
  "action_requested": "NONE",
  "human_approval_required": true,
  "reason_for_no_trade": null,
  "forecast": {"horizon_hours": 24, "probability_up": 0.5}
}
```

Field rules:

| Field | Rule |
|---|---|
| `as_of` | UTC timestamp with a zone (`Z`). Use the snapshot's time. |
| `horizon` | Required, e.g. `"24h"`, `"3d"`. |
| `decision` | `NO_TRADE`, `WATCH`, `LONG_CANDIDATE`, `SHORT_CANDIDATE` (analysis only) or `EXIT_REVIEW`. |
| `NO_TRADE` | Requires `reason_for_no_trade` (a sentence). |
| `LONG_CANDIDATE` / `SHORT_CANDIDATE` | Require non-empty `quantitative_evidence`, `counter_evidence`, `uncertainties`, `invalidation_conditions` and a `stop_plan`. |
| `*_evidence[].kind` | `observed_fact`, `source_claim`, `model_estimate`, `interpretation` or `hypothesis`. |
| `*_evidence[].statement` | 5–600 characters. |
| `evidence_ids` | Only ids returned by tools in this session. Quantitative and ML items must cite at least one. |
| `news_evidence[]` | Needs `evidence_ids` or `source_urls`; add `published_at` (or `"unknown"`) and `observed_at`. |
| `knowledge_references` | Knowledge document ids such as `kb-risk-no-trade-conditions`. |
| `expected_net_return` | Always `null` (no validated return model). |
| `data_quality_status` | `ok`, `degraded` or `unknown`. |
| `llm_confidence_label` | `low`, `medium` or `high`; it is not a probability. |
| `action_requested` | `NONE`, or `REQUEST_RISK_VALIDATION` only for `LONG_CANDIDATE` / `EXIT_REVIEW`. |
| `human_approval_required` | Always `true`. |
| `forecast` | Always include it. `probability_up` = your probability that the last closed 1h close 24h after the report is recorded is above the last closed 1h close now. `0.5` = no view. It is scored against the historical base rate (`research/protocols/llm-decision-eval-v1.md`), so give a calibrated number from the evidence, not a confident-sounding one. It is a view, not a trade signal, and does not change the decision rules above. |

`decision_id` and `trace_id` are generated by the backend; read them from the tool result.
